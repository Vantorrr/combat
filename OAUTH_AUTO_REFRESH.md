# 🔄 Автоматическое обновление OAuth токена

## 🎯 Проблема
Google OAuth токены истекают каждый час. Раньше приходилось вручную обновлять токен в Railway каждый месяц.

## ✅ Решение
Теперь токен автоматически обновляется и сохраняется в PostgreSQL!

---

## 📋 Что изменилось?

### 1. **Новая модель БД: `OAuthToken`**
Токен теперь хранится в базе данных, а не только в переменных окружения.

### 2. **Автоматическое обновление**
При истечении `access_token` он автоматически обновляется через `refresh_token` и сохраняется в БД.

### 3. **Приоритет загрузки**
```
1. База данных (приоритет)
2. Файл token.json (для локальной разработки)
3. ENV переменная (fallback)
```

## 🔧 Техническая информация

### Файлы изменений:
- `models/database.py` - модель OAuthToken
- `services/google_sheets_oauth.py` - логика загрузки/сохранения токена
- `bot/handlers/auth.py` - сохранение токена при авторизации
- `scripts/migrate_token_to_db.py` - миграция токена в БД
- `scripts/test_oauth_from_db.py` - тесты

### Как работает:

1. **При старте бота:**
   - Загружается токен из БД
   - Если токена нет в БД - ищет в файле/env
   - Найденный токен сохраняется в БД

2. **При истечении токена:**
   - Google OAuth автоматически обновляет `access_token` через `refresh_token`
   - Обновленный токен сохраняется в БД
   - Никаких действий от администратора не требуется!

3. **При повторном запуске бота:**
   - Загружается уже обновленный токен из БД

## ❓ FAQ

**Q: Нужно ли обновлять переменную `GOOGLE_OAUTH_TOKEN_JSON_B64` в Railway?**  
A: Нет! Больше не нужно. Токен хранится в БД и обновляется автоматически.

**Q: Что делать если токен слетел?**  
A: Запустите команду `/auth` в боте и следуйте инструкциям. Новый токен автоматически сохранится в БД.

**Q: Как проверить что токен обновляется?**  
A: Посмотрите логи Railway. При обновлении токена появится сообщение:
```
✅ OAuth token refreshed and saved to database
```

**Q: Что делать при переезде на новый сервер?**  
A: Запустите миграцию: `python scripts/migrate_token_to_db.py` или используйте команду `/auth` в боте.
